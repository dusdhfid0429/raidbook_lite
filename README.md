# RaidBook Lite

Discord 보스 알림 · 음성채널 인원체크 · 전리품 경매 봇 (Watchdog + Boss Bot).

## 기능
- 보스 알림 메시지(정각/일일 반복) + 🎙️ 인원체크 버튼(관리자) → 음성채널 접속자를 참석자로 기록
- `/인원현황`(운영진: "운영진" 역할이 있는 사람) → 입력한 음성채널의 현재 인원을 혈맹별 숫자로 그 채널 채팅에 표시 (보스 알림은 안 건드림)
- 마감된 알림에 ➕ 인원 추가(서버 멤버 검색·자동완성) / ➖ 인원 제거(그 알림 참석자만 목록) 버튼(운영진) → Excel·알림 참석자 함께 갱신
- 📦 획득 아이템: 알림 메시지에서 득템 기록 (`반지 x2`처럼 수량)
- 🔨 경매생성: 기록된 아이템 목록에서 하나를 골라 시작가·호가·카운트를 칸마다 입력 → 경매장에 경매 메시지
  → 관리자가 ▶️ 경매시작, 참석자는 🙋 입찰만. 같은 아이템 여러 개는 (1/2)(2/2)로 따로, 낙찰된 건 목록에서 빠짐
  → 진행자(운영진)가 ⏱️ 경매 마감을 누르면 카운트(생성 시 지정, 기본 5초) 시작 — TTS 봇이 경매장 음성채널에서 숫자를 읽음. 카운트 중 입찰이 오면 카운트 취소 후 경매 계속, 입찰 없이 누르면 유찰 (`auction_manual_close: false`면 예전처럼 입찰 후 자동 카운트)
  → 입찰에 성공하면 누른 사람에게만 "✅ 입찰 완료" 확인 메시지, 거부되면 이유 안내
  → 낙찰 결과는 경매장 메시지와 Excel 획득자 칸에만 남음 (보스 알림에는 안 실림). 유찰은 🔁 유찰 재경매 또는 경매생성에서 다시
- 📌 경매 대기 목록: 경매장 맨 아래에 항상 하나. 낙찰되지 않은 아이템을 기간 상관없이 상태별(유찰·경매 전)로 보여 주고(낙찰되면 빠짐), 목록에서 고르면 경매 생성 팝업(관리자). 🙈로 경매 안 할 아이템 제외
- 🛡️ 권한: 기능별 권한 표(`RaidBook_perms.py`) 하나로 확인. 운영진 = 서버 소유자 또는 `운영진` 역할(admin_role_names)·admin_role_ids 역할 보유자 (○○운영진 역할은 표시용)
- 💰 경매 정산: 낙찰된 아이템이 있는 끝난 경매 메시지에만 정산 버튼(관리자). 낙찰금을 config `settlement`(혈비/운영진/참석자 %, 합 100) 비율로 나누고 참석자 몫은 참석자 수로 나눠 Data/auction_settlements.json에 저장. 자투리는 혈비. 결과는 누른 관리자에게만 보임
- 필요한 채널(보탐-알림·보탐-명령·경매장·raidbook-관리)이 없으면 시작 시 'RaidBook' 카테고리에 자동 생성 (봇에 '채널 관리' 권한 필요)
- 🎵 Music Bot(별도 프로그램, 보스봇 토큰 공유): `/재생 <유튜브 링크·재생목록·검색어>` → 입력한 사람의 음성채널에서 스트리밍.
  `/건너뛰기` `/일시정지` `/정지` `/대기열` `/삭제` `/볼륨` `/현재곡`, 재생 메시지의 ⏯⏭⏹📜 버튼. 설정은 `Config/music_config.json`
  동시 재생: `extra_tokens`(설정 마법사 4단계)에 음악 전용 봇 토큰을 넣은 수만큼의 음성채널에서 대기열을 따로 두고 재생 (보스봇은 명령·패널만, 토큰이 없을 때만 보스봇이 재생).
  /재생은 음악 채널과 모든 음성채널 채팅에서 사용 가능 (`allow_voice_chat`)
  (yt-dlp·deno는 첫 실행 시 `Tools/`에 자동 설치·매일 업데이트, ffmpeg.exe는 설치파일에 포함)
- Watchdog: 봇 자동 재시작, 관리 채널 `!panel` 원격 제어 패널(상태·시작·중지·재시작·로그·업데이트)

## 설치 / 업데이트
1. [Releases](../../releases)에서 `RaidBook_Setup_x.y.z.exe` 실행 (관리자 권한 불필요)
2. 설정·데이터 위치: `C:\ProgramData\RaidBook\` (Config, Data, Log) — 업데이트해도 유지
3. 비공개 저장소이므로 업데이트 확인용 토큰을 `C:\ProgramData\RaidBook\Config\github_token.txt`에 넣는다 (Contents: Read-only 권한의 fine-grained PAT)
4. 업데이트: GUI 🔄 버튼 또는 Discord `!panel` → ⬆️ 업데이트 (무인 설치 후 자동 재실행)

## 릴리즈 (개발자)
1. `version.py`의 `VERSION_*` 올리기
2. main에 push (version.py 변경이 감지되면 자동 빌드)
3. GitHub Actions가 Windows에서 빌드 → Release에 설치파일 업로드

## 소스 실행
```powershell
pip install -r requirements.txt
python RaidBook_Watchdog_GUI.py   # 또는 RaidBook_Watchdog_GUI.vbs (콘솔 숨김)
```
